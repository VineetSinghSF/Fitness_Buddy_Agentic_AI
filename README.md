# 🏋️ Fitness Buddy – AI Powered Personal Fitness Coach

## 📌 Project Overview

Fitness Buddy is an AI-powered virtual fitness coach developed using IBM Granite Models, IBM watsonx.ai, and LangFlow. The system provides personalized fitness guidance, workout recommendations, healthy lifestyle suggestions, and motivational support to help users maintain a healthy and active lifestyle.

The project was developed as part of the IBM SkillsBuild 4-Week Internship Program (2026).

---

## 🚀 Problem Statement

### Problem Statement No. 13 – Fitness Buddy

In today's fast-paced world, many individuals struggle to maintain a healthy lifestyle due to:

- Lack of personalized fitness guidance
- Time constraints
- Inconsistent motivation
- Expensive fitness subscriptions
- Non-flexible workout schedules

Fitness Buddy solves this challenge by providing an intelligent AI assistant that can:

- Recommend home workout routines
- Suggest healthy meal ideas
- Provide daily fitness motivation
- Encourage healthy habits and consistency
- Offer personalized fitness guidance

## 🏗️ Architecture

The system uses a multi-agent architecture where different agents collaborate to provide personalized fitness recommendations.

- User enters fitness goals
- Granite Model processes request
- Specialized agents generate recommendations
- Results are combined
- User receives personalized fitness guidance
